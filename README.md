# Chocolate Company Sales Analysis

## Project Overview

This project presents an interactive Power BI dashboard developed to analyze the sales performance of a chocolate company. The dashboard provides insights into gross sales, product performance, regional sales, customer trends, and other key business metrics, enabling stakeholders to make informed business decisions.

---

## Dataset Information

Dataset Name: **Chocolate Company Sales Dataset**

### Dataset Includes
- Geographic Information
- Promotion Information
- Product Information
- Fact Sales Details
- Gross Sales
- Channel
- Dates

---

## Recommendations

- Increase inventory for top-selling products.
- Focus marketing efforts on high-performing regions.
- Improve sales performance in low-performing areas.
- Introduce promotional campaigns during low-sales periods.
- Monitor monthly sales trends for better forecasting.
